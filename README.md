# CK_BlackView

Strona **blackviewgaming.pl**: PlayPop 8, mini PC i ekrany przenośne Blackview w kontekście gamingowym.

## Stan: makieta do akceptacji

Statyczny HTML + CSS bez budowania. Żeby zobaczyć stronę, otwórz `index.html` w przeglądarce.

| Plik | Zawartość |
|---|---|
| `index.html` | Strona główna: hero jasny/ciemny, 3 ścieżki, granie w chmurze, PlayPop, social |
| `playpop.html` | PlayPop 8, rodzinna konsola ruchowa (własna, kolorowa stylistyka) |
| `minipc.html` | MP20, MP50, MP100, MP100 Pro, MP300, NEX60: tryb biurowy i tryb gamingowy |
| `ekrany.html` | Ekrany przenośne SCM, DCM, Table |
| `assets/css/style.css` | Wspólne style |
| `assets/img/` | Grafiki zmniejszone do wersji webowej (źródła na SharePoint) |

Oznaczenia w treści:
- `XXX zł`: ceny do uzupełnienia;
- ramki „packshot z SharePoint”: brakujące grafiki;
- `[…]`: kwestie do decyzji.
